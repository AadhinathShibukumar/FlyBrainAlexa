FlyBrainAlexa is an experimental project that combines a Drosophila (fruit fly) connectome, spiking neural networks, and biomechanical simulation to explore how neural activity can drive realistic behaviour. Using FlyWire-derived neural connectivity data, the project simulates sensory-to-motor processing in PyTorch and links it to a physically simulated fly running in FlyGym/MuJoCo. The codebase is organised into modular brain, body, and Alexa components, with a reusable FlyBody system handling biomechanics and locomotion. Recent work has replaced random motor commands with a biologically inspired tripod gait controller, laying the groundwork for direct brain-to-body control through connectome-derived motor signals.
